# Weekly report

When asked to prepare a weekly report:

1. Establish the reporting period and the intended audience.
2. Use available typed tools to collect only the records needed for that period.
3. Separate completed work, measurable outcomes, blockers, and next steps.
4. Preserve source IDs or document links returned by tools when useful for traceability.
5. Do not invent progress, owners, dates, or metrics.

Recommended output:

```markdown
## 本周完成
- ...

## 结果与数据
- ...

## 风险与阻塞
- ...

## 下周计划
- ...
```
