# Feishu Agent Platform

企业私有飞书多 Agent 运行平台的管理面与管理 API。容器启动时从私有制品存储安装与源代码提交一一对应的不可变运行时产物；首次启动进入 setup mode，请在 `/admin` 完成应用、Agent 与绑定的配置发布。

源码、文档与交付证据见 GitHub 仓库：[BlueSkyXN/Feishu-AgentPlatform](https://github.com/BlueSkyXN/Feishu-AgentPlatform)。
